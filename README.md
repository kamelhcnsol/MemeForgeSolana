# MemeForge Landing Page

Mobile-first static landing page using the existing MemeForge logo and banner.

## Free publishing
Use GitHub Pages. Upload this folder to a public GitHub repository, then Settings → Pages → Deploy from `main` / root. GitHub Pages publishes static HTML/CSS/JS directly.

## Google Analytics 4
Create a GA4 Web data stream and copy the Measurement ID (starts with `G-`). Replace both `G-XXXXXXXXXX` strings in `index.html` with that ID, then upload the updated file. The main X and Telegram buttons already send GA4 events.

## Campaign tracking
Example X URL:
`https://YOUR-GITHUB-URL/?utm_source=x&utm_medium=social&utm_campaign=memeforge`

Example Telegram URL:
`https://YOUR-GITHUB-URL/?utm_source=telegram&utm_medium=social&utm_campaign=memeforge`
